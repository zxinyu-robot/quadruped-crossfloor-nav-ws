## 文档使用规则

1. 阶段、范围和验收以《完整技术路线》为主。
2. 字段和指标细化见《下行JSON建议与分模块评价体系》。
3. 当前动作与状态见《项目执行计划》。
4. 《中间件现状与缺口》仅记录工程现状、边界和缺口。
5. 《契约对齐_第一步决策》仅保留为历史决策记录。

契约本身的定义见 [`docs/contracts/`](../contracts/)。
